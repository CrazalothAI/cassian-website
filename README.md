# Cassian — Min10 Studios

Public website for Cassian. Company: Min10Tech LLC. Original project provenance: **Crazaloth**.

This repository contains only the static website: semantic HTML, local CSS, vanilla ES modules, and original hardware artwork. The desktop DAW source, audio libraries, recordings, screenshots and credentials are excluded.

GitHub Pages serves the root of `main` with `.nojekyll`. The static files were generated with the `/cassian-website/` project prefix. The website was validated by all 35 website tests and the bounded Pages artifact builder before publication. No hosted build or paid Actions runner is required to build these files.

The live download check retains the original official GitHub Releases endpoint and fails closed when a verified release is unavailable. Paid sales, cloud sync and the community Discord invite are pending. Original software source is licensed AGPL-3.0-or-later; see LICENSE.txt. Keep third-party notices intact.

Source website edits are maintained alongside the private Cassian application; only the approved static publication is copied here. To update, regenerate the bounded Pages artifact with `/cassian-website/`, replace the corresponding static files and commit to `main`.
