# Cassian — Min10 Studios

Public website for Cassian. Company: Min10Tech LLC. Original project provenance: **Crazaloth**.

This repository contains only the static website: semantic HTML, local CSS, vanilla ES modules, and original hardware artwork. The live desktop DAW repository, its history, newer unreleased work, private audio, recordings and credentials are excluded from this Git tree. Release attachments separately provide the owner-approved 4.5.1 installer, portable build and matching AGPL source snapshot.

GitHub Pages serves the root of `main` with `.nojekyll`. The static files were generated with the `/cassian-website/` project prefix. The website was validated by all 35 website tests and the bounded Pages artifact builder before publication. No hosted build or paid Actions runner is required to build these files.

The live download check uses the fixed public `CrazalothAI/cassian-website` GitHub Releases endpoint. It validates the complete installer/portable/source/report/checksum set and fails closed on invalid metadata. No private-repository credential is shipped to visitors. Paid sales, cloud sync and the community Discord invite are pending. Original software source is licensed AGPL-3.0-or-later; see LICENSE.txt. Keep third-party notices intact.

Source website edits are maintained alongside the private Cassian application; only the approved static publication is copied here. To update, regenerate the bounded Pages artifact with `/cassian-website/`, replace the corresponding static files and commit to `main`.
