Cassian is presented by Min10 Studios, the music brand of Min10Tech LLC. This website is a product and download site. It does not provide an account system, checkout, analytics, advertising, newsletter signup or a database for visitor messages.

What the website does

The home page reads public release metadata from the fixed Cassian repository on GitHub. Ordinary requests reveal normal connection information, such as your IP address and browser details, to the hosting provider and GitHub. Their infrastructure may retain operational or security logs. The public website is hosted on GitHub Pages and requires no ChatGPT or GitHub sign-in to browse or download. GitHub sign-in is needed only if you choose to submit an issue.

There is no website-to-desktop connection. The site does not request microphone/camera access, inspect installed software, contact localhost or read your guitar recordings, rigs or files.

Suggestions stay a draft until you choose

Suggestion fields exist in the page while it is open. They are not stored by this website or sent automatically. Choosing “Review & submit on GitHub” opens a GitHub issue draft containing the text in its URL. GitHub then receives that text, and you decide whether to submit it. Do not include credentials, private contact details or private recordings.

Downloads and external links

Downloads come from the official GitHub release assets. Following repository, guide, license and issue links uses GitHub’s services and policies. Copy SHA256 writes only the displayed digest to your clipboard when you press the button.

Cookies and local storage

The website’s own code sets no cookies and uses no local/session storage, service worker or tracking pixels. Hosting authentication and infrastructure operate under the provider’s own policies.

Questions

Use the public issue tracker for non-sensitive questions. Cassian is free. Community help uses GitHub; do not post secrets or sensitive personal information publicly. A dedicated private security-reporting channel is being prepared.
